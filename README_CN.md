# DeepSeek Harness 订阅账号插件 · DSH 0.2.2 适配版

Codex、Antigravity 直接在 Harness 内使用；无需运行 CLIProxyAPI 服务。此分支以 DSH 0.2.2-rc.5 做离线验证，使用插件条目的可热更新配置保存偏好、模型目录和图片列表；账号仍保存在 Harness 的独立凭据记录中。旧版的三个设置命名空间不自动迁移。如为首次安装，不需要迁移。

- **强化 Antigravity 工具参数 Schema 兼容性**：深度兼容 Harness 工具复杂 schema（联合类型 `oneOf`/`anyOf`/`allOf`、`const` 以及各类字符串/数字/数组约束），将其投影为 Google Gemini 严格子集结构，将约束平滑转入 description，彻底解决带联合类型/约束的工具声明被拒问题。
- **打包与依赖优化**：同步版本至 2.3.5。

## 升级

你当前使用的是 Electron 独占管理的 `desktop` profile，命令行会拒绝修改它。请在 **Harness 已安装的插件管理器**中安装本地 `dsh-cliproxyapi-2.3.4.tgz`，然后重启应用。

**安装后需要重启 Harness 才能加载新代码**。已有登录凭据和模型偏好会保留；插件激活后会自动刷新已登录账号的额度与模型目录，也可在“设置 → 订阅账号”中手动刷新。普通 Web 安装可用 `dsh plugin --profile web add 包路径`；`npx` 安装则使用 `npx @deepseek-ai/dsh plugin --profile web add 包路径`。

## 模型设置

“设置 → 订阅账号”中展开对应渠道的“模型设置”，也可以直接搜索模型。

- **开放**：决定模型是否在模型选择器显示。关闭后，保存的会话和直接请求也不能继续使用该模型。
- **上下文 Token**：填写完整整数；清空恢复上游默认。有效值通过 Harness 的模型上下文元数据生效，驱动其上下文管理；不会凭空扩大上游模型的实际能力。已知上限取 `max_context_window`，无此字段时取目录上下文长度。
- **思考强度**：按模型目录实际支持的等级选择，包含目录提供的 low、medium、high、xhigh、max、ultra 等。设置为该模型默认值，会话内显式选择的强度优先。不支持或未声明的等级不冒充可用。
- **输出详略**：上游支持时可选简略、标准、详细，实际传入 Codex `text.verbosity`。
- **图片识别**：允许将已上传或工具读取的图片发送给模型。明确声明仅文本的模型不能用开关增加视觉能力。

每行点击“保存”才生效。刷新目录不会清除上述选择，也不会覆盖未保存的界面草稿。

## 图片生成、编辑与识别

- 在聊天中正常上传图片，选择已开放图片识别的模型，即可描述、分析图片。插件通过 Harness 附件服务读取和缩放图片，向 Codex 发送 `input_image`，向 Antigravity 发送 `inlineData`。
- 设置页中的“图片生成与编辑”可选择订阅渠道、图片模型、质量和尺寸；可上传最多 5 张明确的参考图进行编辑。
- Codex 默认图片模型为 `gpt-image-2`，调用订阅专用 `/images/generations` 或 `/images/edits`；该模型的实际使用资格由上游账号决定。
- Antigravity 图片模型来自其目录中声明图片输出的条目，通过 daily 订阅端点调用。其质量和尺寸暂使用上游默认值。
- 启用图片功能后，会话可调用原生工具 `cpa_image_generate`。编辑只允许引用当前会话中的图片，不会悄悄变成无参考图的新图生成。
- 图片保存到 Harness 的附件存储，设置页提供预览、查看原图和下载；原图通过文件附件原样保存。最近 50 项可在设置页访问；会话中的图片仍按 Harness 会话存储管理。

图片生成不会在失败后自动切换账号、模型或付费渠道。图片接口、参考图、附件保存与渲染经过模拟响应测试；本次未消耗订阅额度生成真实图片。

## 网络与错误

默认自动使用环境变量或 Windows 已启用的系统 HTTP 代理，也可在设置页手动指定地址或选择直连。代理变化在下一次请求生效。插件不启动外部代理程序，不修改系统代理。

429 本身不等于账号额度耗尽。插件只有在上游明确返回 `QUOTA_EXHAUSTED`、`usage_limit_reached` 等原因时才显示配额耗尽，其余作为限流或资源暂不可用，并保留上游给出的等待时间。DNS、连接和 TLS 错误分别显示，不在界面或日志中输出令牌。
